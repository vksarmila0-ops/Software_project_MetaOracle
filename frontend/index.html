📘 Academic Viva Voce & Theory Defense Guide

Comprehensive theoretical questions, mathematical foundations, and defense answers for MetaOracle.

1. What is the Test Oracle Problem, and why does Metamorphic Testing solve it?

In software engineering, the Test Oracle Problem refers to situations where verifying whether the program's output is correct is practically impossible, cost-prohibitive, or computationally undecidable (e.g., machine learning, graph shortest paths, simulations, search engines).

Metamorphic Testing (MT) bypasses this problem by checking properties between multiple executions rather than the absolute output of a single execution. Even if we don't know the exact sorted order or shortest distance, we know that reversing an input to a sorting algorithm should produce an identical sorted output (f(rev(x)) == f(x)). A violation guarantees a defect.

2. Why is a Metamorphic Relation violation not absolute mathematical proof of a bug?

A metamorphic relation violation mathematically proves that the quadruple (x, x', f(x), f(x')) violates relation R. This outcome has two possible origins:
Case A (Implementation Bug): The function implementation has an actual defect (e.g. reverse input bias, dropping duplicates).
Case B (Invalid Relation Assumption): The user or tester incorrectly applied an invariant that does not hold for the function's domain (e.g. applying undirected graph symmetry dist(u, v) == dist(v, u) to a directed graph with one-way streets).

3. Why can't static AST analysis discover all Metamorphic Relations automatically?

According to Rice's Theorem, any non-trivial semantic property of a universal computer program is undecidable. An algorithm cannot inspect arbitrary source code and automatically prove which algebraic invariants the human developer intended. MetaOracle implements an intelligent heuristic recommender combining AST structural pattern matching, parameter names, loop patterns, and docstrings to suggest candidate relations with confidence levels (High/Medium/Low) for human confirmation.

4. What is Mutation Testing and how does MetaOracle compute Mutation Score?

Mutation testing intentionally injects small artificial syntactic faults (mutants) into the program using operators:
• ROR (Relational Operator Replacement): > to <, == to !=
• AOR (Arithmetic Operator Replacement): + to -, * to //
• LCR (Logical Connector Replacement): and to or
• COR (Constant Inversion): True to False
The Mutation Score is calculated as:
Mutation Score = (Killed Mutants / Total Non-Equivalent Mutants) × 100%
